## 1. 项目概述（CA-Repeat-Instructions.pdf）

- **课程**: M.Sc. in DevOps 2025/2026 — Enterprise Architecture Deployment
- **讲师**: Dr Omar Portillo

在之前的模块中，学生已经用 CI/CD Pipeline（微软 Azure 或类似云厂商）部署过一个单体 Web 应用。DevOps 正在向微服务架构风格转型。**本作业目标：深入调研并实现一套企业级、基于微服务架构风格的 CI/CD 部署**，架构须包含：

- **至少4个服务**
- **1个数据层**
- **至少涉及2个不同的实体（entity）**

作业包含两部分：
1. 调研 + 配套报告
2. 一个松耦合的、服务化的应用，部署在**真正自动化**的 CI/CD 流水线上

### 微服务部署（可选起点）

官方提供了简单的起始服务（可选择基于其扩展）：
- 动态前端（Node.js）
- Java Web 服务后端
- MongoDB 数据库
- 功能：一个非常基础的"食谱管理" Web 应用

**也可以完全自建**，使用自己选择的编程语言和业务功能。

### 调研要求

需要为你的企业级 CI/CD 部署产出详细的 **发布管理计划（Release Management Plan, RMP）**，研究并评估 CI/测试/部署方案。**工具选择是次要的**——应根据实际工作需要选择合适的工具，而不是反过来因为工具决定怎么做。

**硬性要求**：
- 必须**完全自动化（IaC）** provisioning 和发布编排，包含完善的自动化发布管理计划（自动化基础设施交付 + 持续配置管理），以真正实现持续交付（Continuous Delivery）的承诺。
- 必须有**一致且可重复的变更管理流程**，并且**支持/使用两种不同的部署策略**。
- 部署必须能够**可靠、自动化地销毁并重建**容器编排系统（例如用 Terraform provision 基础设施后，后续更新如何部署？如何在维持 blue-green 部署风格的同时做到这点？）

需要考虑的问题示例：
- 用什么部署策略？
- 每个服务是否要有独立代码仓库？
- 每个服务是否要有独立 CI/CD Pipeline？
- 如何统一所有版本和工具？
- 如何让构建以同样的自动化方式运行？
- 备份恢复策略是什么？

### 研究报告要求

报告须详细说明并论证你的部署策略，并按以下（不限于）标准做评估与批判：
1. Performance（性能）
2. Ease of configuration and installation（配置/安装易用性）
3. Cost and Licensing（成本与许可）
4. Monitoring and logging（监控与日志）
5. Scaling in/out（伸缩）
6. Rollback plan（回滚计划）
7. Backup and restore strategy（备份恢复策略）
8. Security（安全）
9. Support（支持）
10. Vulnerability checks on images（镜像漏洞检查）
11. Sustainability（可持续性）

### GenAI 使用规则

按 TU Dublin 负责任使用 GenAI 的指引，本作业**允许 Level 3（AI辅助编辑）**。必须在报告中讨论具体用法，清楚描述"学生本人在 GenAI 工具之外增加的价值"，并**将所有使用过的 prompt 作为附录列出**。

## 3. 报告大纲（CA-Repeat-ReportOverview.pdf，"CA Repeat Appendix"）

报告写作要求：
1. 将各主题的研究发现总结为一个有机整体
2. 包含简短的引言和结论，总结你的发现
3. 包含参考文献部分（**Harvard 格式**）和参考书目（列出相关但未直接引用的资料）
4. 详细说明你认为自己额外增加的工作
5. 指出各领域的差距和/或感知到的缺陷
6. 大约（不限于）**2000字**
7. 尽量提供平衡、相对客观的批判性评估，正反两方面论证不同方法论/工具
8. 清楚说明未达成的CA要求，以及已实现的附加功能

报告应涵盖的主题：

1. **微服务应用总览**
   - 整体架构总览：服务数量、部署位置、通信方式
   - 数据层如何设计与集成
2. **容器编排 API**
   - 使用了什么容器编排API，为什么
   - 性能；配置/安装易用性；成本；许可；支持；安全
3. **持续软件交付**
   - 使用了什么CI/CD工具
   - 每个服务是否有独立仓库？
   - 每个服务是否有独立CI/CD流水线？
   - 流水线总览、流水线内任务总览
   - 是持续交付还是持续部署？
4. **部署策略**
   - 详细说明并论证你的部署策略
   - 回滚计划
   - 备份恢复策略
   - 定义伸缩策略
5. **自动化基础设施交付**
   - 伸缩（扩缩容）
   - 添加了什么自动化基础设施交付（防止配置漂移）
6. **持续配置管理计划**
   - 是否有一致且可重复的变更管理流程
   - 部署应能可靠、自动化地重建容器
   - 讨论备份恢复策略
7. **容器监控与日志策略**
   - 日志架构总览
   - 日志在哪里
   - 如何监控整个应用
8. **安全**
   - 云端安全
   - 流水线安全
   - 容器安全（镜像漏洞检查等）
   - 数据安全
9. **可持续性**
   - 方案的优势
   - 弱点/可改进之处
   - 设计决策中的可持续性权衡
10. **GenAI 使用**
    - 讨论具体用法（使用了哪些工具、用途）
    - 描述学生本人在GenAI工具之外增加的价值
    - 附录列出所有使用过的prompt
