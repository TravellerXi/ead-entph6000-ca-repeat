# AI 协作记录（供报告 GenAI 附录参考）

> 本文件记录本项目调研/规划阶段与 AI 助手的协作过程，用于满足 CA Repeat 报告中"GenAI usage"章节的强制披露要求（需说明工具、用途、学生本人增加的价值，并附所有 prompt）。**请在正式写报告时，从本文件整理/翻译成英文并放入附录**，不要直接照抄——报告里还需要你自己描述"在AI之外你增加了什么价值"。

## 使用的工具

- **工具**: GitHub Copilot Chat（VS Code）
- **模型**: Claude Sonnet 5
- **使用阶段**: 需求调研、课程内容通读、CA Repeat要求分析、项目脚手架搭建（**不包括**：实际业务代码编写、架构最终决策、报告正文撰写、视频录制、Brightspace提交——这些仍需学生本人完成）

## AI 协助完成的内容摘要

1. 读取 Brightspace 课程列表，确认当前在修课程
2. 读取 Enterprise Architecture Deployment 课程大纲、作业列表、内容模块
3. 核实 CA1 / CA2 / CA Repeat 的提交状态与评分反馈，判断是否仍需补交
4. 通读课程全部13周讲座、实验、演示命令，总结每周技术栈
5. 结合评分标准，设计 CA Repeat 微服务架构方案（4服务+1数据层+2实体）、技术选型、两种部署策略、附加功能建议、10天执行计划
6. 从 Brightspace 下载官方要求文件（说明/评分标准/报告大纲 PDF）与起始代码（BE/FE zip），解压并搭建项目文档骨架

## AI 能力边界（已向学生说明）

- ✅ 可自主完成：代码/配置/IaC脚本编写、终端调试、文档整理、报告初稿结构
- ❌ 不能/不应自主完成：需要交互登录的环境安装（Docker Desktop等）、Azure/云端花费类资源开通、GitHub Secrets等密钥配置、演示视频录制（需学生本人讲解以证明理解）、Brightspace最终提交
- ⚠️ 学术诚信提醒：课程明确只允许 **Level 3（AI-Assisted Editing，AI辅助编辑）**，不是全权代做；评分标准明确"无法解释自己的工作会被扣分"，讲师9月可能视频抽查
